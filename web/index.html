AIO-Feeder
Install Demo Guide Source

Feed several tanks from one touchscreen

AIO-Feeder is a touchscreen controller and one small wireless feeder per tank. Each feeder keeps its own clock and schedule, so the fish are fed even when the controller is switched off.

Try the controller in your browser

Install the firmware

Plug the board into this computer with a USB data cable and press its button below. This needs Chrome or Edge on a desktop computer.

Controller

Waveshare ESP32-S3-Touch-LCD-4.3B. Use the USB-C port marked UART.

This browser cannot flash boards. Use Chrome or Edge on a desktop computer. Flashing needs a secure (https) page.

Feeder

ESP8266 NodeMCU V3 with a DS3231 clock and a relay. One per tank.

This browser cannot flash boards. Use Chrome or Edge on a desktop computer. Flashing needs a secure (https) page.

What it does

Schedules per tank

Several feeding times a day, chosen weekdays, and a portion for each one.

Keeps feeding on its own

A feeder stores its schedule and runs it from a battery-backed clock.

Guards against overfeeding

A hard limit on every pulse, a cooldown between feeds and a daily cap.

History and alerts

Every feed and every refused feed is reported back and listed.

No router needed

Controller and feeders talk directly. Wi-Fi is optional, for internet time and updates.

Updates without a cable

After the first install, both devices update from a web page on your network.
